## 🚀 Featured Projects

<details open>
<summary><b>🏛️ IRIS ZONE — Integrated Reporting & Infrastructure System</b></summary>

<br/>

**Stack:** `Java 17` · `Spring Boot` · `MySQL (AWS RDS)` · `AWS S3` · `OpenStreetMap Nominatim API` · `Google Gemini Multimodal Vision API`

An AI-assisted civic complaint platform. Citizens report infrastructure issues with a photo and location, the system verifies the image with multimodal AI, resolves the location, and routes the complaint to the right authority automatically. It is the basis of a provisional patent specification.

| Stack | Scale | Performance | Security | Impact | Repository |
|:---|:---|:---|:---|:---|:---|
| Java 17, Spring Boot, MySQL (AWS RDS), AWS S3, Nominatim | Cloud-hosted relational store and object storage designed to grow with complaint volume | Automated verification and routing replace manual triage | Validated inputs, controlled media storage, managed cloud database | Faster, more transparent civic complaint resolution | [View Repository](https://github.com/gn-shanthaveeragowda) |

- 🧩 **Layered Spring Boot backend:** controller, service and repository layers over MySQL on AWS RDS.
- 🖼️ **Multimodal verification:** Gemini Vision analyses uploaded images to confirm and categorise the reported issue.
- 🗺️ **Geospatial routing:** Nominatim geocoding plus Haversine distance resolves the location and selects the responsible authority.
- ☁️ **Cloud storage:** complaint media is stored in AWS S3, with metadata persisted in RDS.
- 🔁 **Deterministic hybrid agent:** AI output feeds rule-based routing, so decisions stay predictable and auditable.

</details>

<details open>

<br/>

**Stack:** `Java` · `Spring Boot` · `MySQL` · `REST APIs` · `Google Gemini API` · `HTML5` · `CSS3` · `JavaScript`

An assessment platform for universities that generates quizzes with an LLM, delivers them through a web interface, and evaluates results automatically. It was **Runner-Up at the 2026 Project Exhibition** at Bangalore Technological Institute.

| Stack | Scale | Performance | Security | Impact | Repository |

- 🧱 **REST-first backend:** Spring Boot services expose quiz, attempt and result endpoints over MySQL.
- ✨ **LLM-assisted generation:** Gemini API produces questions from course topics, with structured parsing of responses.
- 🖥️ **Lightweight frontend:** HTML5, CSS3 and JavaScript deliver a responsive quiz-taking experience.
- 📊 **Automated evaluation:** scoring and result storage are handled server-side for consistency.
